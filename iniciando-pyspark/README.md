# Conhecendo PySpark 🚀

Este projeto faz parte do repositório **Data-Science-Beginner** e tem como objetivo um **primeiro contato com o PySpark**, explorando manipulação e análise de dados em larga escala dentro do Google Colab.

Os dados utilizados neste estudo são oriundos da **Receita Federal do Brasil** (base de empresas e estabelecimentos), que foram tratados e analisados com PySpark.

---

## 🧑‍🎓 Sobre o projeto
- Introdução prática ao **PySpark** em ambiente de notebooks.
- Operações básicas de manipulação e transformação de dados.
- Análises iniciais usando a base pública da Receita Federal.
- Exercício voltado para aprendizado de **Big Data** e integração com **Data Science**.

---

## 🛠️ Tecnologias utilizadas
- **Python**
- **Google Colab**
- **PySpark**
